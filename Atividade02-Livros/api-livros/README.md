Atividade 02: Consumo e Criação de API

Projeto simples feito para praticar APIs com Laravel.

O que o projeto faz
Consome uma API pública: busca dados de pokémons na PokéAPI.
Tem uma API própria: um CRUD de livros (listar, criar, ver, editar e excluir) com rotas RESTful, Resource e validação.
Cliente em outro framework: um site em Flask (Python) que usa a API de livros para listar, cadastrar e excluir.
Testes no Postman: a collection está na pasta postman.
